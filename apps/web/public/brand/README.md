# Brand assets (owner-supplied)

No artwork is generated by the coding agent. Until these files exist, the app uses
the plain text wordmark "Omnitool" in Schibsted Grotesk and Lucide icons.

Target paths, from `docs/design/ART-PROMPTS.md`:

| File | Purpose | Size |
|------|---------|------|
| `logo.svg` | Light-background wordmark or mark | vector |
| `logo-dark.svg` | Dark-background variant | vector |
| `favicon.svg` | Simplified ring and notch | 16–32 px legible |
| `icon-512.png` | PWA icon | 512 x 512 |
| `icon-192.png` | PWA icon | 192 x 192 |
| `apple-touch-icon.png` | iOS home screen | 180 x 180 |
| `og.png` | Social preview | 1200 x 630 |

Empty-state spots go in `apps/web/src/assets/spots/`:

- `drop.svg` (drop a file here)
- `empty.svg` (no results)
- `offline.svg` (works offline)

When the files arrive, wire them into `index.html`, the Vite PWA manifest and the
three empty states. Record provenance in `docs/legal/ART-PROVENANCE.md`.
